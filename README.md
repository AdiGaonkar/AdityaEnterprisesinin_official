Getting Started

Prerequisites

Make sure you have the following installed:

- "Node.js" (https://nodejs.org/)
- npm
- Git
- VS Code or another preferred IDE

Clone the Repository

git clone <YOUR_GIT_REPOSITORY_URL>

Navigate to the project:

cd AdityaEnterprises

Install Dependencies

npm install

Start the Development Server

npm run dev

The development server will normally be available at:

http://localhost:5173

---

Making Changes

You can work on the project using:

VS Code

Clone the repository, open it in VS Code, make your changes, and run:

npm run dev

GitHub Codespaces

The project can also be opened directly in GitHub Codespaces.

After making changes:

git add .
git commit -m "Update website"
git push

GitHub

Individual files can also be edited directly through GitHub using the Edit option.

Development Guidelines

When contributing to the project:

1. Keep the existing design system consistent.
2. Use reusable React components wherever possible.
3. Maintain responsive layouts for mobile, tablet, and desktop.
4. Keep TypeScript types properly defined.
5. Avoid unnecessary dependencies.
6. Test changes locally before pushing.
7. Use meaningful Git commit messages.

Example:

git add .
git commit -m "Add product details page"
git push

---

Environment Variables

If the project uses external services such as Supabase, required environment variables should be stored in a local ".env" file.

Example:

VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_key

«Never commit private API keys, passwords, service-role keys, or other sensitive credentials to GitHub.»
